# Рекомендательная система банка «Стар»

## 📌 Описание проекта

Проект представляет собой рекомендательную систему для банка «Стар», которая анализирует транзакционную активность пользователей и предлагает персонализированные банковские продукты. Система поддерживает как статические, так и динамические правила рекомендаций, а также предоставляет Telegram-бота для выдачи рекомендаций пользователям.

## 📌 Стек технологий

- **Backend**: Spring Boot 4.0.3+
- **Database**: H2 Database (встраиваемый режим)
- **API**: REST API
- **Documentation**: OpenAPI (Swagger)
- **Telegram integration**: Telegram API

## 📌 Функциональность

- **Статические и динамические правила**: Система поддерживает как заранее заданные, так и настраиваемые правила рекомендаций.
- **Статистика срабатываний**: Возможность просмотра статистики по динамическим правилам.
- **Telegram-бот**: Предоставление рекомендаций через Telegram-бот.
- **Административные функции**: Управление динамическими правилами, сброс кеша, получение информации о приложении.
